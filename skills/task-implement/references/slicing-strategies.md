# 拆分策略

## 垂直切分（推荐）

每个增量交付一个完整的功能链路，端到端可用：

```
增量 1：连接设备（端口抽象 + Fake + 连接按钮）→ 可连上
增量 2：接收状态（解析 + 模型 + 状态栏）→ 可显示
增量 3：下发命令（校验 + 发送 + 结果提示）→ 可控制
增量 4：断线重连（状态机 + UI 禁用）→ 完整会话
```

## 契约优先

UI 与设备/协议可并行时采用：

```
增量 1：定义端口接口与帧结构（头文件 + Fake）
增量 2：按契约实现解析器 + ViewModel（测 Fake）
增量 3：接真实适配器联调
```

## 风险优先

优先验证最高风险的部分：

```
增量 1：验证串口/TCP 连通与帧边界 → 不通过则及时止损
增量 2：在已验证的链路上构建业务状态机
增量 3：实现重连、超时与看门狗
```

## 增量标准

| 指标 | 建议 |
|------|------|
| 代码行数 | ≤100 行/增量 |
| 涉及文件 | ≤3 个/增量 |
| 验收标准 | 1–2 条/增量 |

每个增量完成后：
- [ ] 测试套件全部通过
- [ ] 构建成功
- [ ] 已提交
