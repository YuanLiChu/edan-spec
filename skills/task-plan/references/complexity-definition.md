# 复杂度分级标准

任务复杂度的分级标准。

---

## 分级标准表

| 大小 | 文件数 | 人天 | 代码量 | 依赖数 | 典型场景 |
|------|--------|------|--------|--------|----------|
| XS | 1 | ≤0.25 | ≤50行 | 0 | 单方法、简单逻辑、无依赖 |
| S | 2 | 0.25-0.5 | 50-150行 | ≤1 | 单功能、少量代码、简单UI组件 |
| M | 3-4 | 0.5-1.5 | 150-300行 | ≤2 | 功能切片、多方法、中等逻辑 |
| L | 5-7 | 1.5-3 | 300-600行 | ≥3 | 多组件交互、复杂逻辑、外部依赖 |
| XL | 8+ | — | — | — | **必须拆分** |

---

## 分级判断维度

### 一、文件数量

| 文件数 | 大小 |
|--------|------|
| 1个文件 | XS |
| 2个文件 | S |
| 3-4个文件 | M |
| 5-7个文件 | L |
| 8+个文件 | XL（需拆分） |

### 二、代码量估算

| 代码量 | 大小 |
|--------|------|
| ≤50行 | XS |
| 50-150行 | S |
| 150-300行 | M |
| 300-600行 | L |
| ≥600行 | XL（需拆分） |

### 三、依赖数量

| 依赖数 | 大小影响 |
|--------|----------|
| 0 | XS |
| ≤1个依赖 | S |
| ≤2个依赖 | M |
| ≥3个依赖 | L |
| 外部接口依赖 | 提升1级 |

### 四、逻辑难度

| 逻辑类型 | 大小影响 |
|----------|----------|
| 简单逻辑（单方法、数据展示） | XS |
| 中等逻辑（表单验证、数据处理） | S/M |
| 复杂逻辑（算法、性能优化、加密） | L |

---

## 典型场景示例

### XS级（≤0.25人天）

| 场景 | 说明 |
|------|------|
| 单接口实现 | 单一CRUD接口（获取用户信息） |
| 简单UI组件 | 单一页面（登录页面） |
| 文档编写 | 技术文档、用户手册 |
| 单元测试 | ≤5个用例 |

### S级（0.25-0.5人天）

| 场景 | 说明 |
|------|------|
| 单组件 | 单一UI组件（表单组件） |
| 单端点 | 单一API端点（用户创建） |
| 配置更改 | 配置文件修改、依赖更新 |

### M级（0.5-1.5人天）

| 场景 | 说明 |
|------|------|
| 功能切片 | 用户注册流程（数据库 + API + UI） |
| 多接口实现 | 用户CRUD + Token管理 |
| 复杂UI逻辑 | 表单验证 + 错误提示 + 状态管理 |
| 单元测试 | 5-10个用例 |

### L级（1.5-3人天）

| 场景 | 说明 |
|------|------|
| 多模块集成 | 前端 + 后端 + 第三方接口 |
| 复杂算法 | 加密算法、图像处理 |
| 性能优化 | 响应时间优化、并发处理 |
| 外部接口联调 | 支付接口、地图接口 |

### XL级（必须拆分）

| 场景 | 拆分建议 |
|------|----------|
| 多子系统 | 按子系统拆分为多个M任务 |
| 全栈功能 | 拆分为数据库、API、UI三个M任务 |
| 大型重构 | 按模块拆分为多个L任务 |

---

## 分级调整规则

分级后可根据以下因素调整：

| 调整因素 | 影响 |
|----------|------|
| 新技术使用 | 提升1级 |
| 外部接口依赖 | 提升1级 |
| 高风险任务 | 提升1级 |
| 团队不熟悉领域 | 提升1级 |

**示例**：登录接口实现
- 基础复杂度：M（多方法实现）
- 技术难度：JWT加密（新技术）→ 提升1级
- 最终复杂度：L

---

## 拆分标志

以下信号表明任务需要拆分：

| 信号 | 说明 |
|------|------|
| 验收标准 > 3条 | 拆分为多个任务 |
| 任务标题包含"和" | 这是两个任务（"实现登录和注册" → 拆分） |
| 涉及多个子系统 | 按子系统拆分 |
| 预估 > 2小时专注工作 | 拆分为可单次完成的任务 |
| 文件数 > 8个 | XL级别，必须拆分 |

---

## 工时计算公式

见 `risk-classification.md` 中的权威定义：

```
缓冲工时 = 基础工时 × 缓冲系数 × 风险等级系数
总工时 = 基础工时 + 缓冲工时
```

风险缓冲系数与风险等级系数详见 `risk-classification.md`。
