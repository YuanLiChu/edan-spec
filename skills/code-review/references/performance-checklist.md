# 性能检查清单

用于代码审查中的性能维度检查。

## Core Web Vitals
- LCP < 2.5s
- INP < 200ms
- CLS < 0.1

## 前端性能
- [ ] 图片优化（WebP/AVIF、适当尺寸、懒加载）
- [ ] JavaScript 拆分（code splitting、tree shaking）
- [ ] CSS 优化（critical CSS、移除未使用样式）
- [ ] 字体优化（font-display: swap、子集化）
- [ ] 减少主线程长任务（>50ms）
- [ ] 避免内存泄漏（事件监听器清理）

## 后端性能
- [ ] 数据库查询使用索引
- [ ] 避免 N+1 查询（join 或批量加载）
- [ ] API 响应分页/懒加载
- [ ] 连接池配置合理
- [ ] 缓存热点数据

## API 响应时间基线
- 简单查询：< 100ms
- 复杂查询：< 500ms
- 批量操作：< 1s

## Android 性能
- [ ] 冷启动 < 2s
- [ ] 帧率稳定 60fps
- [ ] 内存无泄漏（MAT/LeakCanary）
- [ ] 网络请求合并/缓存

## 常见反模式
- 循环中的数据库查询或 I/O
- 不必要的深拷贝
- 同步阻塞主线程
- 未关闭的资源（连接、流、监听器）
- 过度渲染/重排
