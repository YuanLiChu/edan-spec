# 通用编码风格

所有语言适用的编码约束。语言特定规则见 `java/` 或 `kotlin/` 目录。

## 注释要求

- [必须]  所有方法都需要进行注释
- [必须]  注释中需要添加“EDAN”标识


## 不可变性

- [必须]  创建新对象，不修改现有对象
- [必须]  使用不可变数据结构和写时复制
- [禁止] 原地修改

## 文件组织

- [必须]  按功能/领域组织，不按类型
- [必须]  高内聚，低耦合
- [必须]  文件大小：200-400 行（最多 800 行）

## 错误处理

- [必须]  每层明确处理错误
- [必须]  UI 提供友好错误消息
- [必须]  服务器记录详细错误上下文
- [禁止] 静默吞掉错误

## 输入验证

- [必须]  系统边界验证所有用户输入
- [必须]  使用 schema 验证（可用时）
- [必须]  快速失败，清晰错误消息
- [禁止] 信任外部数据

## 函数大小

- [必须]  函数 <50 行
- [禁止] 深层嵌套（≤ 3 层）

## 禁止行为

- [禁止]  硬编码值（用常量或配置）
- [禁止]  原地修改
- [禁止]  静默吞掉错误
