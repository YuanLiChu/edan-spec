# 通用编码风格

所有语言适用的编码约束。语言特定规则见 `cpp/` 与 `qt/` 目录。

## 注释要求

- [必须]  公共 API（头文件中的类、方法、QML 可见属性）使用 Doxygen 或 Qt 文档注释（`/*!` / `///`）
- [必须]  注释解释 **为什么** 和不变式，不复述代码在做什么
- [必须]  非显然的线程约定、所有权、单位（ms、Hz、物理量）写在声明处
- [禁止]  注释中写入密钥、内网地址、真实账号、客户数据或内部工单号
- [禁止]  已过期的注释（与代码矛盾必须删或改）

## 不可变性与状态

- [必须]  能 const 的局部变量、引用、成员函数都标 const
- [必须]  共享状态的修改路径唯一、可追踪（信号、明确的 setter、事务）
- [禁止]  通过隐藏别名原地改共享对象而不发通知
- [禁止]  在 const 接口背后修改可观察状态（`mutable` 仅用于缓存且须线程安全）

## 文件组织

- [必须]  按功能/领域组织，不按类型堆目录（禁止满仓库 `utils/` 上帝目录）
- [必须]  高内聚，低耦合
- [必须]  文件大小：200-400 行（最多 800 行）
- [必须]  一个翻译单元一个主要职责；`QObject` 子类头/源成对

## 错误处理

- [必须]  每层明确处理错误：捕获、转换或向上传播，不许失踪
- [必须]  UI 提供可行动的友好消息；日志保留可诊断上下文
- [必须]  设备/IO 失败可重试的要有上限与退避
- [禁止]  静默吞掉错误

## 输入验证

- [必须]  系统边界验证所有外部输入（设备报文、文件、网络、QML/用户输入）
- [必须]  校验长度、范围、单位、版本号；失败快速返回
- [禁止]  信任外部数据

## 函数大小

- [必须]  函数 <50 行
- [禁止]  深层嵌套（≤ 3 层）

## 禁止行为

- [禁止]  硬编码魔数（用命名常量或配置）
- [禁止]  硬编码密钥、口令、连接串
- [禁止]  静默吞掉错误
- [禁止]  在提交中夹带调试用的无限日志或注释掉的大段代码
